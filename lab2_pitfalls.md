# Lab 1 Pitfalls to Compare with Lab 2
During the LangChain freeform-agent lab, the main pitfall was that the agent controlled the tool order instead of the developer. This was useful for creative complaint handling because the model could explore different combinations of tools, but it also made the workflow less predictable. A second pitfall was that the agent could choose different tools for similar complaints, which makes evaluation harder. A third pitfall was that verbose output and intermediate steps were needed to understand what the agent actually did. In Lab 2, a LangGraph workflow should improve this by defining clear steps, predictable routing, and a more auditable execution path.
